# System-Uptime-and-Patch-Auditor-Bash-
Bash script to audit Linux system uptime, patch status, security updates, and compliance posture with detailed reporting.
System Uptime and Patch Auditor is an automated Bash-based solution designed to assess Linux server health, uptime, kernel status, installed patches, and pending security updates.
It helps administrators maintain patch compliance, improve security visibility, and streamline operational audits through concise reporting and actionable insights.
